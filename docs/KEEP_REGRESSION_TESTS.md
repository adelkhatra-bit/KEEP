## Comment relancer les tests vérifiables par curl/code (sans device)

Voir les commandes utilisées le 24/08/2026 dans l'historique de session — sinon reconstruire :
1. Créer une identité anonyme fraîche : `POST {SUPABASE_URL}/auth/v1/signup` avec `{}` et la clé anon.
2. Tester le quota : `POST http://localhost:3010/api/recognition/identify` avec le token, 4x de suite.
3. Tester KEEP→Supabase : `POST`/`GET http://localhost:3010/api/social/me/keeps`.
4. Tester le provider AcoustID direct : `fpcalc -json <wav>` puis `GET https://api.acoustid.org/v2/lookup?...`.
5. Tester le provider AudD direct : `POST https://api.audd.io/` multipart avec `api_token`+`file`.
