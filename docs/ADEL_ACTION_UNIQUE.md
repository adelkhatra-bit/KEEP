# Action unique (PC requis, 2 minutes)

1. Ouvrir : https://github.com/settings/tokens?type=beta
2. Chercher le token "KEEP-Agents-Workflow"
3. Cliquer "Regenerate token" (ou "Generate new token" avec les permissions ci-dessous)
4. Permissions obligatoires :
   - Actions : Read and write
   - Contents : Read and write
   - Metadata : Read-only (auto)
   - Workflows : Read and write
5. Générer, copier le token (github_pat_...)
6. Le coller dans une conversation avec Abacus
