# Dessin anime automatique

Projet distinct de Loki Music. Etat: prototype non deploye.

Objectif: produire un episode anime original chaque semaine, un teaser vertical, verifier les fichiers, puis programmer les publications TikTok et YouTube apres validation des connexions et du cout.

Ne jamais stocker de mots de passe ou de jetons dans le code. Les connexions ChatGPT ne sont pas automatiquement des secrets utilisables par GitHub Actions.

Aucun rendu complet ni publication n'est pret a ce stade.
