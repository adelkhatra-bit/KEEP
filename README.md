# KEEP - Musical Recognition & Smart Playlist Management

Musical recognition app that identifies songs, manages playlists intelligently, and connects music lovers.

## Architecture

- **packages/mobile** - React Native/Expo (iOS + Android)
- **packages/backend** - Node.js/Express + Supabase
- **packages/admin** - Next.js Super Admin

## Quick Start

```bash
cd packages/mobile
npm install
npx expo start
```

Scan QR code with Expo Go app (iPhone or Android).
